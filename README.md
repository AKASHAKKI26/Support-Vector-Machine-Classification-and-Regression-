# Machine Learning Projects – Classification and Regression

## Project Overview
This repository contains two Machine Learning projects:

1. SVM Classification using Iris Dataset
2. Insurance Cost Prediction using Regression

These projects demonstrate both classification and regression techniques using Python and Scikit-learn.

---

# Project 1: SVM Classification using Iris Dataset

## Description
This project uses the Support Vector Machine (SVM) algorithm to classify iris flowers into different species based on flower measurements.

---

## Dataset Used
Iris Dataset

### Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Target Classes
- Setosa
- Versicolor
- Virginica

---

## Algorithm Used
- Support Vector Machine (SVM)
- Kernel: RBF

---

## Steps Performed
1. Import libraries
2. Load Iris dataset
3. Split dataset into training and testing sets
4. Create SVM model
5. Train the model
6. Predict output
7. Calculate accuracy

---

## Libraries Used
- NumPy
- Matplotlib
- Scikit-learn

---

## Output
The model predicts iris flower species with high accuracy.

Example:
Accuracy = 1.00

---

# Project 2: Insurance Cost Prediction using Regression

## Description
This project predicts medical insurance charges based on customer details such as age, BMI, smoking habits, and region.

---

## Dataset Used
Insurance Dataset

### Features
- age
- sex
- bmi
- children
- smoker
- region

### Target Variable
- charges

---

## Problem Type
Regression

Because the target variable contains continuous numerical values.

---

## Algorithm Used
- Linear Regression

---

## Steps Performed
1. Import libraries
2. Load dataset
3. Handle missing values
4. Encode categorical data
5. Split dataset into training and testing sets
6. Train regression model
7. Predict insurance charges
8. Evaluate performance

---

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R2 Score

---

## Output
The model predicts medical insurance charges.

Example:
Predicted Insurance Charge = 25000

---

# Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

---

# Conclusion
These projects demonstrate:
- Classification using SVM
- Regression using Linear Regression

Both projects help understand supervised machine learning concepts, model training, prediction, and evaluation techniques.
